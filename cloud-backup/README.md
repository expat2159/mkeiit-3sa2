# Резервная копия в Google Cloud

Cloud Run Job раз в час запускается Cloud Scheduler, сравнивает SHA ветки `main` с `BACKUP_COMMIT.txt` в существующем ZIP Google Диска и при изменении заменяет его содержимое. Копия создаётся из точного Git-коммита через `git archive`. Скрипт проверяет имя, ID и родительскую папку файла; не создаёт новые файлы и не трогает локальные ключи.

Нужны включённый биллинг Google Cloud, проект `mkeiit-schedule-backup` и роль редактора для сервисного аккаунта на конкретном ZIP. Ключи сервисного аккаунта не создаются: задание получает короткоживущий токен с Drive scope через Cloud Run metadata server. При изменении публичного репозитория на приватный понадобится отдельная авторизация GitHub.

Развёртывание создаёт Cloud Run Job, Cloud Scheduler, Cloud Build и Artifact Registry. Возможна стоимость согласно квотам и тарифам Google Cloud; отслеживайте расходы. Текущую автоматизацию ChatGPT следует отключать только после проверки нового задания. Задание и доступ к Drive требуют реальной проверки на проекте — локальные тесты не подтверждают облачную настройку.
