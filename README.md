# 3СА2 · Расписание МКЭиИТ

Неофициальное Android-приложение для группы **3СА2** Мурманского колледжа экономики и информационных технологий.

**разработчик - expat** · [Исходники на GitHub](https://github.com/expat2159/mkeiit-3sa2) · [Источник расписания](https://mkeiit.ru/?page_id=2699)

## Возможности

- Расписание 3СА2 с выбором подгруппы. Общие пары расположены по центру; при выборе одной подгруппы весь текст её пар также выравнивается по центру.
- Лента дней перемещается вслед за пальцем. Прокрутка меняет только видимые даты; для выбора дня нужно нажать на дату. Есть переход к сегодняшнему дню и календарь выбора даты.
- Вкладка «Преподаватели»: плашки с именами, прокрутка списка и поиск по фамилии. По нажатию открывается расписание преподавателя со всеми группами, предметами и кабинетами. Возврат сохраняет поиск и позицию списка.
- Вкладка «Звонки»: оригинальное изображение с сайта целиком помещается в доступную область. По нажатию открывается на весь экран.
- Кнопки обновления, настроек, закрытия, навигации по неделям, возврата к списку и «Сегодня» используют скруглённую форму, тематические цвета, контурные значки и эффект нажатия без стандартных серых рамок Android.
- Светлая и тёмная темы; режим «Авто» следует теме телефона. Выбор сохраняется между запусками. В настройках также находятся подпись «разработчик - expat» и контакт «Telegram разработчика», открывающий https://t.me/expat2159. Ссылка на GitHub из настроек убрана.
- Расписание выбранного дня отображается компактной таблицей без вертикальной прокрутки. Нажатия на пары не открывают дополнительных окон.

Приложение написано на **Java**, интерфейс использует стандартные компоненты Android. Скрипт сборки — Python. Минимальная версия Android — **8.0 (API 26)**, целевая — Android 15 (API 35). Сервисы Google, аккаунт и собственный сервер не нужны.

Окно выбора даты выполнено в стиле приложения: скруглённая карточка, палитра текущей темы, сетка с понедельника, цветное выделение выбранной даты и контур сегодняшней. Кнопки переключают месяцы с переходом между годами. «Сегодня» выбирает текущую дату внутри окна; «Выбрать» применяет её, «Отмена» оставляет прежнюю. Одинаковый календарь используется для группы и преподавателей. На низком экране содержимое окна можно прокрутить.

Картинку звонков можно увеличивать двумя пальцами до 6× и перемещать одним пальцем. Жесты работают во вкладке и на весь экран. При уменьшении до исходного размера изображение снова целиком помещается в области просмотра; перетаскивание ограничено краями изображения. Обычное нажатие при исходном масштабе открывает полный экран.

## Загрузка, обновления и офлайн

Ссылки на недели, группу и преподавателей обнаруживаются на сайте; идентификаторы конкретных людей и группы не зашиты. Загружаются текущая опубликованная неделя (либо ближайшая предыдущая) и ближайшая будущая, если она опубликована. Даты определяются по Москве.

Расписание группы, список преподавателей и звонки проверяются примерно раз в сутки через Android JobScheduler. Задача сохраняется после перезагрузки. Android и EMUI могут откладывать запуск для экономии энергии; точное время обновления не гарантируется. При открытии проверяются данные старше суток, кнопка «Обновить» запускает проверку вручную.

Расписания преподавателей загружаются при первом открытии и сохраняются локально. Затем обновляются ранее открывавшиеся преподаватели; остальные заранее не скачиваются. Кэши группы/звонков и преподавателей разделены. При ошибке загрузки сохранённые данные остаются доступны. Отсутствие данных на дату не обозначается как отсутствие занятий.

При обновлении каждый файл проверяется отдельно условным HTTP-запросом. Если сервер отвечает 304, тело файла не передаётся, используется сохранённая версия. Поддерживаются ETag и Last-Modified; для статических страниц этого сайта, которые не присылают Last-Modified, используется время сервера Date с запасом в две секунды. Проверено, что сайт учитывает такой If-Modified-Since. Если сервер перестанет учитывать условия, приложение скачает файл и сравнит SHA-256. Изменение каталога не требуется для проверки отдельных расписаний преподавателей.

После установки версии 1.11 первая проверка заполняет новый HTTP-кэш. Далее загружаются изменившиеся файлы; навигационные страницы также проверяются, а главная страница может передаваться целиком, если сервер не поддерживает условные запросы. Неизменившиеся расписания повторно не разбираются. Результат проверки отображается внутри приложения в строке статуса на три секунды, без системного Toast. При сворачивании сообщение очищается; завершение проверки в фоне не показывает его поверх других приложений. В конце проверки показывается результат: «Изменений нет», перечень обновлённых разделов или сообщение о неполной проверке. HTTP-кэш ограничен 64 МиБ и очищает старые файлы; удалённый файл при следующем обращении скачивается заново.

Первое открытие требует интернета. На Huawei для фоновой работы разрешите приложению автозапуск и работу в фоне в настройках телефона: «Батарея → Запуск приложений». Названия пунктов могут отличаться.

## Сборка

### Android Studio / Gradle

Откройте корневую папку как Gradle-проект. Нужны **JDK 17**, **Gradle 8.9**, **Android SDK 35** и доступ к Google/Maven для Android Gradle Plugin 8.7.3.

```sh
gradle :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

### Без Gradle

Нужны Java, Python 3, Android SDK Platform 35, Build Tools 35.0.0 и [ECJ 3.38.0](https://repo.maven.apache.org/maven2/org/eclipse/jdt/ecj/3.38.0/ecj-3.38.0.jar).

```sh
python3 build-apk.py --sdk /path/to/android-sdk --ecj /path/to/ecj-3.38.0.jar
```

APK: `dist/3SA2-raspisanie-1.15.apk`. Скрипт компилирует приложение, упаковывает ресурсы и проверяет подпись. Ключ подписи в репозиторий не включён: самостоятельная сборка получит другую подпись. Каталоги сборки, APK, локальные настройки и ключи исключены из Git.

Jsoup 1.18.3 включён в `app/libs`. Его лицензия MIT присутствует внутри JAR и в `app/src/main/assets/jsoup-LICENSE.txt`.

## Проверки

Отдельный тест HTTP-кэша проверяет ответы 200/304, независимость файлов, ETag, время сервера, восстановление после перезапуска, повреждения кэша и ошибки сети.

Чистые Java-тесты используют сохранённые публичные HTML-страницы сайта. Проверяются кодировки, обнаружение недель и преподавателей, даты, обе подгруппы, rowspan/colspan, группы/предметы/кабинеты преподавателей, выходной и неизвестная дата, офлайн-сериализация, прокрутка ленты дат, выбор темы и контраст текста.

```sh
mkdir -p build/tests
javac -encoding UTF-8 -cp app/libs/jsoup-1.18.3.jar -d build/tests \
  app/src/main/java/ru/mkeiit/schedule/Timetable.java \
  app/src/main/java/ru/mkeiit/schedule/Bells.java \
  app/src/main/java/ru/mkeiit/schedule/CalendarDates.java \
  app/src/main/java/ru/mkeiit/schedule/DayStripPosition.java \
  app/src/main/java/ru/mkeiit/schedule/Teachers.java \
  app/src/main/java/ru/mkeiit/schedule/AppColors.java \
  app/src/main/java/ru/mkeiit/schedule/ConditionalHttpCache.java tests/*.java
for test in ParserTest BellsTest CalendarTest DayStripTest TeachersTest AppColorsTest; do
  java -cp build/tests:app/libs/jsoup-1.18.3.jar "$test"
done
java -cp build/tests:app/libs/jsoup-1.18.3.jar ru.mkeiit.schedule.ConditionalHttpCacheTest
```

На Windows замените `:` в classpath на `;` и запустите тесты отдельными командами.

Проверка фоновой задачи с подключённым телефоном:

```sh
adb shell cmd jobscheduler run -f ru.mkeiit.schedule 302
adb shell dumpsys jobscheduler ru.mkeiit.schedule
```

На устройстве следует проверить темы, смену системной темы в режиме «Авто», возврат к списку преподавателей, загрузку в авиарежиме после первого просмотра и обновление поверх предыдущей версии. Новые изменения интерфейса не проверялись на физическом Huawei в среде сборки.
